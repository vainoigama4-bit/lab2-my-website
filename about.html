Về tôi

Tôi là sinh viên năm 2 ngành Công nghệ thông tin, hiện đang tìm hiểu sâu hơn về lập trình web. Tôi thích tự tay xây dựng các dự án nhỏ để rèn luyện kỹ năng thực hành.

Ngoài lập trình, tôi cũng dành thời gian tìm hiểu về Git, GitHub và các công cụ hỗ trợ làm việc nhóm trong dự án phần mềm.

Một số thuật ngữ tôi đã nắm vững

HTML
HyperText Markup Language - ngôn ngữ đánh dấu siêu văn bản, dùng để xây dựng cấu trúc trang web.
CSS
Cascading Style Sheets - ngôn ngữ định dạng, trang trí giao diện trang web.
Git
Hệ thống quản lý phiên bản mã nguồn, giúp theo dõi và lưu lại lịch sử thay đổi code.

Kỹ năng

  • HTML5
  • CSS3
  • JavaScript cơ bản
  • Git & GitHub

Lộ trình học tập

  1. Nắm vững HTML, CSS nâng cao
  2. Học sâu hơn về JavaScript và thao tác với DOM
  3. Thực hành xây dựng một dự án web hoàn chỉnh
